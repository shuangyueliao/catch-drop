# Catch Drop · 接住水果

Free single-file HTML5 arcade game. Move the basket, catch falling fruit,
chain catches for combo multipliers, dodge bombs. 3 lives, one HTML file,
zero assets.

**Play:** https://shuangyueliao.github.io/catch-drop/

- Mouse / touch / arrow keys, procedural WebAudio sounds (catch / gold / bomb / miss)
- Procedural fruit, woven basket, orchard backdrop — no dependencies
- Best score saved locally, mute toggle
